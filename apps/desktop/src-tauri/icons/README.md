# OpenBook Studio app icons

These icons are **original OpenBook Studio placeholder artwork** generated for this repository.

They replace the default Tauri project-scaffold icons (which depicted Tauri’s trademarked mark). OpenBook does **not** claim or redistribute Tauri, React, or other third-party logos as product branding.

Source master: `apps/desktop/assets/openbook-app-icon-1024.png`  
Regenerate with:

```bash
npm run tauri -w @openbook/desktop -- icon apps/desktop/assets/openbook-app-icon-1024.png
```

Do not commit Tauri (or other third-party) trademark artwork into this folder.
