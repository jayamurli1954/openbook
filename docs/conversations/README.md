# OpenBook Conversation Archive

This directory contains concise records of important OpenBook conversations.

## Purpose

The archive preserves the reasoning and context behind durable project decisions. It complements, but does not replace, ADRs and other authoritative project documents.

## Recording format

Each conversation record should normally contain:

- Conversation ID
- Date
- Topic
- Context
- Key discussion points
- Alternatives considered
- Decisions reached
- Open questions
- Action items
- Related ADRs/documents

## Authority

Conversation records are historical/reference material. Accepted or Frozen ADRs, specifications and governance policies remain authoritative when there is a conflict.

## Naming convention

Use:

`YYYY-MM-DD-<short-topic>.md`

Example:

`2026-09-03-epubcheck-java-tauri.md`

## Workflow

1. Capture the important conversation.
2. Extract durable decisions.
3. Update/create the relevant ADR, specification, architecture or policy.
4. Add the decision to the master decision index.
5. Record unresolved items in the decision backlog.
6. Link the conversation record to the resulting project documents.
